# Emotion Face-Off Game

The **Emotion Face-Off Game** is a web-based application developed using the Flask framework. The project explores the comparison between human perception and artificial intelligence (AI) in recognizing facial emotions.

Participants are asked to identify emotions from facial images. Their responses are then compared with predictions generated by an AI emotion recognition model. The platform also functions as a research tool to collect and analyse pilot data on human vs AI emotion recognition.

---

## 🌟 Features

- Interactive emotion recognition game
- Comparison between user guesses and AI predictions
- Individual results feedback
- Dashboard displaying aggregated results
- Data collection for research analysis
- Analytical scripts to evaluate human and AI accuracy

---

## 🧠 Emotions Included

The game evaluates recognition across seven emotional categories:

- Angry  
- Disgust  
- Fear  
- Happy  
- Sad  
- Surprise  
- Neutral
